# get CNV allele posteriors

get CNV allele posteriors

## Usage

``` r
get_allele_post(df_allele, haplotypes, segs_consensus)
```

## Arguments

- df_allele:

  dataframe Allele counts

- haplotypes:

  dataframe Haplotype classification

- segs_consensus:

  dataframe Consensus CNV segments

## Value

dataframe Allele posteriors
