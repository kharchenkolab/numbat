# Annotate a set of segments on a pseudobulk dataframe

Annotate a set of segments on a pseudobulk dataframe

## Usage

``` r
annot_consensus(bulk, segs_consensus, join_mode = "inner")
```

## Arguments

- bulk:

  dataframe Pseudobulk profile

- segs_consensus:

  datatframe Consensus segment dataframe

## Value

dataframe Pseudobulk profile
